## C) Proposed Information Architecture (5–7 Main Nav Items)

**Navigation Streamline:** Simplify to five core sections, aligning content with the user journey and trust requirements. The new top nav would be:

1. **Overview** – *What it is & How it works* (High-level product overview in plain language).  
   *Content:* A cohesive introduction to TerminaI’s purpose and core concepts. This will combine the essence of the current home page hero, “Why it exists” manifesto snippets[\[24\]](https://github.com/Prof-Harita/terminai-website/blob/85f0785dcc516eb517f53f1b3313e9e917f778ee/src/app/manifesto/page.tsx#L53-L61)[\[25\]](https://github.com/Prof-Harita/terminai-website/blob/85f0785dcc516eb517f53f1b3313e9e917f778ee/src/app/manifesto/page.tsx#L84-L92), and key features. It should explain the *System Operator* model and how TerminaI works (the intent → plan → approve → execute cycle[\[26\]](https://github.com/Prof-Harita/terminaI/blob/f27ef96120727feba69517aa24a74d002cd1b013/README.md#L52-L60)[\[27\]](https://github.com/Prof-Harita/terminaI/blob/f27ef96120727feba69517aa24a74d002cd1b013/README.md#L220-L229)) in a newbie-friendly narrative. *(If not a separate page, the home page will serve this role with clearly labeled sections.)*

2. **Quickstart** – *Your First Win* (Guided first-use path).  
   *Content:* A beginner’s “Start Here” guide to get TerminaI running and accomplish a first useful task within minutes. This will leverage the existing **Start Here** page structure[\[28\]](https://github.com/Prof-Harita/terminai-website/blob/85f0785dcc516eb517f53f1b3313e9e917f778ee/src/app/start/page.tsx#L60-L68)[\[29\]](https://github.com/Prof-Harita/terminai-website/blob/85f0785dcc516eb517f53f1b3313e9e917f778ee/src/app/start/page.tsx#L91-L100), organized by persona/use-case (Everyday user, Sysadmin, Developer). This reduces overwhelm and immediately demonstrates the tool’s utility.

3. **Recipes** – *Community Solutions* (Examples & templates).  
   *Content:* The existing **Recipes Library** page showcasing community-contributed “prompt recipes”[\[30\]](https://github.com/Prof-Harita/terminai-website/blob/85f0785dcc516eb517f53f1b3313e9e917f778ee/src/app/recipes/page.tsx#L20-L28)[\[31\]](https://github.com/Prof-Harita/terminai-website/blob/85f0785dcc516eb517f53f1b3313e9e917f778ee/src/app/recipes/page.tsx#L30-L38). It will list common tasks and automation patterns by category, each with a short description, risk level, and tags (as currently implemented). This helps users discover what TerminaI can do (“fix Wi-Fi”, “cleanup downloads folder”, etc.) and copy safe, pre-vetted command recipes. It also invites contribution of new recipes (with a CTA to the contributing guide[\[32\]](https://github.com/Prof-Harita/terminai-website/blob/85f0785dcc516eb517f53f1b3313e9e917f778ee/src/app/recipes/page.tsx#L62-L70)). This section appeals to the builder community’s desire to share and reuse solutions.

4. **Trust & Safety** – *Why you can trust it* (Governance model and security).  
   *Content:* A dedicated page merging the **Safety** and **Trust Center** content. It will summarize TerminaI’s safety architecture in approachable terms. Key elements: the **Approval Ladder** (Level A/B/C with examples of actions at each tier[\[33\]](https://github.com/Prof-Harita/terminai-website/blob/85f0785dcc516eb517f53f1b3313e9e917f778ee/src/app/safety/page.tsx#L174-L183)[\[34\]](https://github.com/Prof-Harita/terminai-website/blob/85f0785dcc516eb517f53f1b3313e9e917f778ee/src/app/safety/page.tsx#L208-L217)), **Audit Trails** (what is logged and where[\[11\]](https://github.com/Prof-Harita/terminai-website/blob/85f0785dcc516eb517f53f1b3313e9e917f778ee/src/app/safety/page.tsx#L238-L246)[\[12\]](https://github.com/Prof-Harita/terminai-website/blob/85f0785dcc516eb517f53f1b3313e9e917f778ee/src/app/safety/page.tsx#L280-L288)), **Privacy** (local-first execution, no telemetry by default, bring-your-own API keys[\[35\]](https://github.com/Prof-Harita/terminai-website/blob/85f0785dcc516eb517f53f1b3313e9e917f778ee/src/app/terms/page.tsx#L86-L94)[\[36\]](https://github.com/Prof-Harita/terminai-website/blob/85f0785dcc516eb517f53f1b3313e9e917f778ee/src/app/trust/page.tsx#L32-L40)), and **Governance Principles** (reinforcing that nothing happens without user consent[\[37\]](https://github.com/Prof-Harita/terminai-website/blob/85f0785dcc516eb517f53f1b3313e9e917f778ee/src/app/safety/page.tsx#L24-L31)[\[38\]](https://github.com/Prof-Harita/terminai-website/blob/85f0785dcc516eb517f53f1b3313e9e917f778ee/src/app/safety/page.tsx#L50-L58)). It gives skeptical users peace of mind by detailing safeguards and explicitly stating “No, it won’t run amok or phone home.”

5. **Contribute** – *Get Involved* (Community & dev links).  
   *Content:* The contributor information hub, based on the current **Contribute** page[\[4\]](https://github.com/Prof-Harita/terminai-website/blob/85f0785dcc516eb517f53f1b3313e9e917f778ee/src/app/contribute/page.tsx#L20-L28)[\[41\]](https://github.com/Prof-Harita/terminai-website/blob/85f0785dcc516eb517f53f1b3313e9e917f778ee/src/app/contribute/page.tsx#L27-L35). It will highlight that TerminaI is an OSS project and welcome participation. Sections for different contribution areas: *Core Engineering* (CLI, policy engine, etc.), *Extensions/Plugins* (MCP, A2A protocols), and *Community* (discussions, issue reporting). This page provides links to GitHub issues, discussion forums, and the CONTRIBUTING.md guide[\[42\]](https://github.com/Prof-Harita/terminai-website/blob/85f0785dcc516eb517f53f1b3313e9e917f778ee/src/app/free/page.tsx#L54-L58). The tone is inviting (“Join us in building the ecosystem”) but avoids any corporate “careers” language.

*Optional:* **Docs** – If the documentation site is extensive, keep a “Documentation” link. This would point to the docs hub (the existing /docs section, which likely is auto-generated from Markdown). It’s not a marketing page but a resource, so it can be last in the nav or just in the footer. Given our audience (builders), providing easy access to detailed docs is valuable, but we’ll keep the nav label simple (“Docs”). All other secondary pages (Updates, Roadmap, Manifesto, Privacy/Terms) will be accessible via the footer or in-page links rather than cluttering the top nav.

**Summary of IA:** The focus is on *What → How → Trust → Extend*. **4\. Five Trust Claims (Precise & Defensible):**

* **Human-Governed Autonomy:** *No command runs without your say-so.* TerminaI classifies every operation by risk (read-only, sensitive, or destructive) and pauses for your approval at the appropriate level[\[33\]](https://github.com/Prof-Harita/terminai-website/blob/85f0785dcc516eb517f53f1b3313e9e917f778ee/src/app/safety/page.tsx#L174-L183)[\[47\]](https://github.com/Prof-Harita/terminai-website/blob/85f0785dcc516eb517f53f1b3313e9e917f778ee/src/app/safety/page.tsx#L208-L216). You’re always in the loop – even “fix it automatically” requires a click or PIN for high-risk steps.

* **Tamper-Evident Audit Log:** *Every action is recorded.* TerminaI keeps a JSONL audit trail of what was proposed, approved, and executed[\[11\]](https://github.com/Prof-Harita/terminai-website/blob/85f0785dcc516eb517f53f1b3313e9e917f778ee/src/app/safety/page.tsx#L238-L246)[\[12\]](https://github.com/Prof-Harita/terminai-website/blob/85f0785dcc516eb517f53f1b3313e9e917f778ee/src/app/safety/page.tsx#L280-L288). If something ever goes wrong, you have a forensic record – no more mystery “AI did something” moments.

* **Local-First & Privacy-Respecting:** *Your data stays with you.* By design, TerminaI runs on your own system and doesn’t phone home. It doesn’t send data outside your computer unless you explicitly connect an API.
