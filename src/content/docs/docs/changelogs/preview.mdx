# Preview release: Release v0.22.0-preview.0


Released: December 16, 2025

Our preview release includes the latest, new, and experimental features. This release may not be as stable as our [latest weekly release](/docs/changelogs/latest).

To install the preview release:

```
npm install -g @google/terminai@preview
```
