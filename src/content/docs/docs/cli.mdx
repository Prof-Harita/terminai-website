## Non-interactive mode

[Section titled “Non-interactive mode”](#non-interactive-mode)

TerminaI can be run in a non-interactive mode, which is useful for scripting and automation. In this mode, you pipe input to the CLI, it executes the command, and then it exits.

The following example pipes a command to TerminaI from your terminal:

Terminal window

```
echo "What is fine tuning?" | gemini
```

You can also use the `--prompt` or `-p` flag:

Terminal window

```
gemini -p "What is fine tuning?"
```

For comprehensive documentation on headless usage, scripting, automation, and advanced examples, see the **[Headless mode](/docs/cli/headless)** guide.
