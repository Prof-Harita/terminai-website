# Get started with TerminaI


Welcome to TerminaI! This guide will help you install, configure, and start using the TerminaI to enhance your workflow right from your terminal.

## Quickstart: Install, authenticate, configure, and use TerminaI

[Section titled “Quickstart: Install, authenticate, configure, and use TerminaI”](#quickstart-install-authenticate-configure-and-use-terminai)

TerminaI brings the power of advanced language models directly to your command line interface. As an AI-powered assistant, TerminaI can help you with a variety of tasks, from understanding and generating code to reviewing and editing documents.

## Install

[Section titled “Install”](#install)

The standard method to install and run TerminaI uses `npm`:

Terminal window

```
npm install -g @google/terminai
```

Once TerminaI is installed, run TerminaI from your command line:

Terminal window

```
gemini
```

For more installation options, see [TerminaI Installation](/docs/get-started/installation).

## Authenticate

[Section titled “Authenticate”](#authenticate)

To begin using TerminaI, you must authenticate with a Google service. In most cases, you can log in with your existing Google account:

1.  Run TerminaI after installation:
    
    Terminal window
    
    ```
    gemini
    ```
    
2.  When asked “How would you like to authenticate for this project?” select **1\. Login with Google**.
    
3.  Select your Google account.
    
4.  Click on **Sign in**.
    

Certain account types may require you to configure a Google Cloud project. For more information, including other authentication methods, see [TerminaI Authentication Setup](/docs/get-started/authentication).
