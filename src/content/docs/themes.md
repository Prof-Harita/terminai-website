# Themes

TerminaI supports custom color schemes.

## Configuration

Edit `~/.terminai/config.json`:

```json
{
  "theme": "dracula"
}
```

## Supported Themes

- System (Default)
- Dracula
- Monokai
- Solarized Light
- Cyberpunk (High Contrast)
